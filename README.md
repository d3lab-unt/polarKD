# PolarKD

> **🆕 Update:** The new, updated version, **PolarKDv2** (LLM-based causal discovery on top of PolarKD), is now available in the [`PolarDS 2026`](./PolarDS%202026/) folder. See its [README](./PolarDS%202026/README.md) for setup and usage. The documentation below is for the previous version.

A local, private, and intelligent system to extract keywords and semantic relationships from uploaded research PDFs and generate an interactive Knowledge Graph.
Built with Streamlit, Neo4j, Ollama, GPT-4o-mini, and PyVis.
